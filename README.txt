EVERYDAY ESSENTIALS - 5 PAGE BUSINESS WEBSITE

FILES
- index.html: Home page
- about.html: About Us page
- products.html: Product catalogue
- reviews.html: Customer reviews and feedback form
- contact.html: Shop details and contact enquiry form
- css/style.css: Common styling for all pages
- js/script.js: Product display, product search/filter and form interactions
- images/: Local SVG product illustrations

HOW TO OPEN
1. Extract the complete project folder.
2. Open index.html in a web browser.
3. Use the navigation menu to visit the other four pages.

CUSTOMISE BEFORE USING FOR A REAL BUSINESS
- Replace "Everyday Essentials" with the actual business name in all five HTML files.
- Update the sample product names, categories, prices, descriptions and image paths in js/script.js.
- Replace the example reviews in js/script.js with genuine customer reviews.
- Replace the address, phone number, email and opening-hour placeholders in contact.html.
- Add a real map or directions link after the shop address is known.

IMPORTANT FUNCTIONALITY NOTES
- Product search and category filtering work in the browser.
- Feedback submitted on the Reviews page is added to the page for the current visit only. It is not saved after reloading or closing the page.
- The Contact form validates the fields and shows a demonstration message. It does not send or store enquiries because no server/backend is included.
- The products, prices, business details and initial reviews are sample/demo content, not verified details for a real shop.

TECHNOLOGY
This project uses HTML, CSS and vanilla JavaScript. No framework, database or external library is required.
